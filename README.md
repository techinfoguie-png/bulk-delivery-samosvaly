# СахалинСнаб — Доставка сыпучих материалов

Сайт по доставке щебня, песка, ПГС и других сыпучих материалов самосвалами в **Южно-Сахалинске**.

### Основные возможности

- ✅ Современный адаптивный дизайн
- ✅ SPA-роутинг (без перезагрузки страниц)
- ✅ Интерактивная карта с построением маршрута (Leaflet + OpenStreetMap)
- ✅ Полноценная CMS на базе Google Sheets
- ✅ Админ-панель с управлением заявками и материалами
- ✅ Автоматические email-уведомления
- ✅ Несколько цветовых тем
- ✅ Мобильное меню (бургер)

### Технологии

- **Frontend**: HTML + CSS + Vanilla JavaScript
- **Хостинг**: GitHub Pages
- **База данных / CMS**: Google Sheets + Google Apps Script
- **Карты**: Leaflet.js + OpenStreetMap
- **Маршруты**: Leaflet Routing Machine

---

### Как запустить сайт

1. Создайте репозиторий на GitHub
2. Включите **GitHub Pages** (Settings → Pages → Source: Deploy from a branch → main)
3. Загрузите все файлы в репозиторий
4. Настройте Google Apps Script (Web App) и вставьте ссылку в `index.html` и `admin.html`
5. Готово! Сайт будет доступен по адресу: `https://ваш-username.github.io/название-репозитория/`

---

### Админ-панель

- Перейдите по ссылке `/admin.html`
- Пароль по умолчанию: `admin123` (обязательно смените в коде!)
