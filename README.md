# ТДТК.РФ — Твой Дом Твоя Крепость

**Город установки:** г. Макаров

Сайт для сбора заявок на установку систем контроля доступа (домофонов) в многоквартирных домах с механикой сбора согласий (>50% квартир для заключения договора).

## 🎯 Функционал

### Главная страница
- **Hero-секция** с анимированным щитом и статистикой
- **4 варианта тарифов:**
  1. Домофон стандарт — 200 ₽/мес (установка бесплатно)
  2. Домофон стандарт — без абонплаты, +10 000 ₽
  3. Домофон + камера на крыльце — 350 ₽/мес (установка бесплатно)
  4. Домофон + камера — без абонплаты, +10 000 ₽
- **Слайдер выполненных работ** с поддержкой свайпа на мобильных
- **Прогресс подъездов** — карточки с % согласия и статусом
- **Форма заявки** с выбором тарифа и маской телефона
- **Полная адаптация** под мобильные устройства

### Админ-панель
- Дашборд со статистикой
- Таблица всех заявок
- Управление подъездами
- Аналитика по тарифам и улицам
- Настройки системы

## 🔧 Настройка Google Forms + Sheets

### 1. Создайте Google Form

Поля формы:
1. **Отметка времени** (автоматически)
2. **Адрес дома** (короткий ответ)
3. **Номер подъезда** (короткий ответ)
4. **Номер квартиры** (короткий ответ)
5. **Всего квартир в подъезде** (короткий ответ)
6. **Тариф** (несколько вариантов):
   - Домофон стандарт, 200р/мес
   - Домофон стандарт, без абонплаты +10000
   - Домофон + камера, 350р/мес
   - Домофон + камера, без абонплаты +10000
7. **Согласие** (несколько вариантов):
   - Да, согласен на установку
   - Пока думаю / Нужна консультация
8. **Телефон** (короткий ответ)
9. **Имя** (короткий ответ)
10. **Комментарий** (абзац)

### 2. Свяжите с Google Sheets

Ответы → Создать электронную таблицу

### 3. Настройте Google Apps Script

Откройте таблицу → Расширения → Apps Script

Вставьте код из файла `google-apps-script.js`

### 4. Замените URL в коде

В `js/app.js` замените:
```javascript
const API_URL = 'ВАШ_URL_GOOGLE_APPS_SCRIPT';
```

В `index.html` замените action формы:
```html
action="ВАШ_URL_GOOGLE_FORM"
```
